# Mineral World / 矿物世界

一个改变 Minecraft 世界生成的 Mod。保留原版地形、群系、结构的形态，将方块替换为矿物。

## 功能

- **主世界**：石头变成铁矿，大地由矿物构成
- **下界**：下界岩变成石英矿
- **末地**：末地石变成黑曜石
- **树木**：每种树木对应不同矿物，树叶变成矿物块
- **兼容**：紫菘果可在矿物底座上生长，下界菌柄树不会长在岩浆里

## 安装

1. 安装对应版本的 Forge 或 Fabric Loader
2. 下载与你 Minecraft 版本匹配的 jar
3. 将 jar 放入 `.minecraft/mods/` 文件夹

**服务端必需，客户端可选安装。**
